# Tendedero Inteligente — SmartLine

Distribución portable para Windows del prototipo educativo **SmartLine**, un
tendedero inteligente con dashboard local, simulación y conexión Arduino.

## Descargar

La aplicación se distribuye únicamente como paquete ejecutable en la sección
**Releases** de este repositorio. El código fuente del proyecto y del firmware
no se publica aquí.

Después de descargar el ZIP, extráelo por completo y consulta
`LEEME_INICIO_RAPIDO.txt` antes de ejecutar `SmartLine.exe`.

## Alcance

Este software corresponde a un prototipo educativo y experimental. El modo de
demostración utiliza datos simulados; no representa una validación física del
hardware ni un sistema industrial certificado.
